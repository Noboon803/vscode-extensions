# CC Session Usage

Claude Code のセッション履歴（`/resume` で再開できる会話）を読み、トークン量とコストを日別、モデル別、プロジェクト別、ターン別に表示する拡張機能です。ユーザーの指摘と質問、それへの対応を一覧にすることもできます。インストール手順は、リポジトリのルートにある `README.md` を参照してください。

**金額は定価で計算した推定です。** 実際の請求額ではありません。Pro や Max などの定額プランでは、請求とは関係のない目安です。

## 使い方

アクティビティバーの CC Session Usage を開きます。

- **現在のセッション:** 開いているフォルダで最後に活動したセッションのターンを、新しい順に表示します。表示中は履歴の変更を追いかけて自動で更新します（最短 2 秒間隔）。ビューの更新ボタンでも読み直せます。項目を選ぶと、詳細画面の該当するターンを開きます。
- **セッション:** 最近のセッションを表示します。項目を選ぶと、詳細画面を開きます。

ビューのグラフのボタン、またはコマンドパレットの `CC Session Usage: 使用量を表示` で、全体の集計を開きます。

- **一覧:** 期間とプロジェクトで絞り込めます。セッション名を選ぶと、そのセッションの詳細を開きます。
- **セッションの詳細:** ターンごとのコスト、トークン量（入力、出力、キャッシュの読み書き）、コンテキスト量、ツール呼び出し、変更行数と、前のターンからの増減を表示します。一覧のセッション名を選ぶと開きます。

## 指摘と質問

画面上部の「指摘と質問」タブに全セッションの一覧を、セッションの詳細画面に「指摘と質問」の欄を表示します。ターンの番号を選ぶと、詳細画面のターン一覧の該当行へ移動します。

**分析はボタンを押したときだけ実行します。** インストール済みの `claude` コマンド（`claude -p`）を呼ぶので費用がかかり、実行前に費用の目安と送信内容を確認します。結果の画面には実際の費用を表示します。分類と要約はモデルによるもので、誤りや漏れがあります。発言の原文は履歴から取ります。

| 項目 | 内容 |
| --- | --- |
| 指摘 | エージェントの作業、回答、判断に対する誤りの指摘、やり直しの要求、不満、方針の訂正、反論、問題の報告 |
| 質問 | 情報や説明を求めた発言。質問の形をした依頼は含みません |
| 対象外 | 新しい依頼、承認、続行の指示、スラッシュコマンド、自動実行のセッション、元の履歴が削除されたセッション |
| 増分 | 分析済みのターンは読み直しません |
| 実行中のセッション | 最後の活動から 10 分以内なら、応答の途中かもしれない最後のターンを対象にしません |

| 送信するもの | 送信しないもの |
| --- | --- |
| ユーザーの発言（1 ターン最大 4000 文字）、応答の本文の末尾（最大 2000 文字）、ツール名と回数 | ツールの入力と実行結果、思考、サブエージェントの会話 |

送信先は `claude` コマンドの接続先です。発言に貼り付けた秘密情報は送信の対象に含まれます。呼び出しでは、ツール、MCP、スラッシュコマンド、利用者の設定（フック、CLAUDE.md、`settings.json`）をすべて無効にし、履歴にも残しません。`settings.json` で認証や接続先を設定している場合は、分析に失敗することがあります。

大きなセッションは 4 万文字ごとに分けて呼び出します。途中で失敗しても成功した分は残り、新しいセッションの処理は始めずに止まります。

## HTML レポート

一覧の各タブとセッションの詳細画面にある「HTML レポートを出力」、またはコマンドパレットの `CC Session Usage: HTML レポートを出力` で保存します。今表示している範囲（期間、プロジェクト、セッション）が対象です。「指摘と質問」タブからは全期間、コマンドパレットからは全プロジェクトの全期間を出力します。

**レポートは毎回同じ形式です。** モデルは使わず、コードの決まった手順で作るので、費用はかかりません。データがないセクションも見出しと表の列を残し、「該当なし」と書きます。

| 順 | セクション | 内容 |
| --- | --- | --- |
| 1 | 概要 | コスト、セッション数、ターン数、トークン量、変更行数、指摘と質問の件数、未分析のターン数 |
| 2 | 指摘と質問 | 日時、種類、発言の要点、対応・回答、状況、セッション、ターン、原文（時刻の古い順） |
| 3 | 日別のコスト | 日付、コスト |
| 4 | モデル別 | モデル、コスト、リクエスト、トークン |
| 5 | プロジェクト別 | プロジェクト、パス、コスト、セッション数 |
| 6 | セッション別 | セッション、プロジェクト、最後の活動、ターン、コスト、指摘、質問、未分析 |
| 7 | ターン別 | セッションごとに、発言、指摘・質問の別、コスト、トークン量、コンテキスト、リクエスト、ツール、変更行 |

**レポートには発言の内容が含まれます。** 共有するときは内容を確認してください。ファイルは単体で開け、スクリプトも外部のファイルも読み込みません。分析していないターンは「指摘と質問」に含まれず、その件数を概要に示します。構成を変えたときは、末尾の「レポート形式」の番号を上げます。

## 集計の決まり

| 項目 | 内容 |
| --- | --- |
| ターン | ユーザーの発言から次の発言まで。通知などで始まった応答は、直前のターンに含めます |
| コスト | 各リクエストの `usage` と単価から計算します。単価は `src/pricing.ts` にあり、表示画面に基準日を示します |
| 未割当 | Claude Code が記録したセッションの累計が計算値より多いときの差です。裏側のリクエストなど、履歴に残らない分と考えられます |
| サブエージェント | 起動元のターンに合算します |
| 変更行数 | Edit と Write の結果から数えます。Bash で編集した分は含みません |

単価表にないモデルは金額に含めず、件数を画面で知らせます。

同じフォルダで複数のセッションを同時に動かしていると、「現在のセッション」は最後に活動したものに切り替わります。要約などのために Claude Code が自動で実行したセッションは対象にしません。

## データの扱い

- 履歴は読むだけで、変更しません。使用量の集計ではネットワークに送信しません。送信するのは、「指摘と質問」の分析を実行したときだけです。
- 集計結果は VS Code の拡張機能用の保存領域（`globalStorage`）にある `usage.json` に保存します。**各ターンの発言の冒頭（最大 200 文字）も含みます。** 分析結果は同じ場所の `review.json` に保存し、**発言の原文（最大 1000 文字）を含みます。** 不要になったら、拡張機能のアンインストールとあわせてこれらのファイルを削除してください。
- Claude Code は古い履歴を既定で 30 日後に削除します（`cleanupPeriodDays`）。この拡張機能は VS Code の起動時に集計を更新するので、削除された履歴の集計も残ります。集計していなかった期間の履歴は取り戻せません。

## 履歴の形式について

履歴の形式は Claude Code の内部仕様で、更新により変わることがあります。解釈できない行があると、件数を画面で知らせます。

読み込むフォルダは、設定 `ccSessionUsage.claudeConfigDir` で変更できます。空の場合は環境変数 `CLAUDE_CONFIG_DIR`、なければ `~/.claude` を使います。分析に使うモデルは `ccSessionUsage.reviewModel`、`claude` コマンドのパスは `ccSessionUsage.claudePath` で変更できます。
