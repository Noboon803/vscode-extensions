# Markdown Viewer

ファイルごとに固定され、スクロールも連動せず、コメントを書き込める Markdown プレビューです。インストール手順は、リポジトリのルートにある `README.md` を参照してください。

VS Code 標準のプレビューとの違いは次のとおりです。

- エディターで別のファイルへ切り替えても、プレビューの内容は変わりません
- エディターとプレビューのスクロールは連動しません
- 複数のプレビューを同時に開けます。同じファイルを 2 つ開くこともできます
- プレビュー上でコメントを書き込めます

## プレビューを開く

次のいずれかで開きます。すでに開いているファイルなら、そのプレビューを前面に出します。

- Markdown を開いているエディターの右上の本のアイコン
- エクスプローラーの右クリックメニューの `Markdown Viewer で開く`（複数選択すると、まとめて開きます）
- コマンドパレットの `Markdown Viewer で開く`（プレビューが前面にあるときはファイルを選びます）
- エディターの選択（`Reopen Editor With...` や `Open With...`）の `Markdown Viewer`。今のタブをプレビューに切り替えます

同じファイルをもう 1 つ開くには、`Markdown Viewer でもう 1 つ開く` を使います。エディター右上のボタンを Option（Windows は Alt）を押しながらクリックしても同じです。

編集中の内容は保存しなくてもプレビューに反映されます。ウィンドウを再読み込みしても、開いていたプレビューとスクロール位置は復元されます。

ショートカットキーは割り当てていません。必要なら `markdownViewer.open` に割り当ててください。

## コメント

- **書き込む:** プレビューで文章を選択して `コメント` を押すか、ブロックにカーソルを合わせて左の `+` を押します。入力欄では Cmd/Ctrl + Enter で追加、Esc で取り消します
- **一覧:** パネルの `コメント` タブ（ターミナルと同じ並び）に、すべてのファイルのコメントを表で表示します。ファイル名を押すと、その位置をプレビューで表示します
- **削除:** プレビューのカード、または表の `×` で削除します。`すべて削除` で全件を削除します
- **コピー:** `箇条書きでコピー` を押すと、次の形式でクリップボードに入ります

```text
- docs/guide.md:12 「選択した文章」: コメント
- README.md:3 「見出し」: 複数行のコメントは
  続きを字下げします
```

実際には `docs/guide.md:12` の部分が Markdown のリンクになり、リンク先は `/docs/guide.md#L12` です。リンク先はワークスペースのルートからのパスで、同じワークスペースの Markdown に貼り付けて使えます（マルチルートでは同じフォルダ内のみ）。ワークスペースの外のファイルは `file:` の URI になります。Markdown Viewer でリンクを押すと、そのファイルのプレビューを開いて該当の行へ移動します。

コメントはワークスペースごとに VS Code の内部に保存され、Markdown ファイルは書き換えません。

ソースを編集して行がずれると、コメントは同じ内容の行へ自動で追従します。対象の行そのものを書き換えると元の位置に留まり、`変更あり` と表示します。元の内容に戻すと表示は消えます。

## 表示できる内容

CommonMark と GFM の表、タスクリスト、リンクの自動認識、コードの構文ハイライトに対応しています。HTML も書けますが、スクリプトは実行せず、`style` と `form` は取り除きます。

相対パスの画像は、ファイルと同じフォルダ以下、または開いているワークスペース内のものを表示できます。Markdown へのリンクを押すと、そのファイルのプレビューを開きます。
